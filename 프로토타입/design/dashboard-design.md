# 대시보드 디자인 가이드

`dashboard.html`에 적용된 디자인을 정리한 문서입니다. 원칙은 하나입니다. **표가 주인공이고, 장식은 없다.**
시스템 설정에 따라 라이트·다크가 자동 전환되며, 두 모드 모두 아래 토큰만 바뀝니다.

## 색 토큰

| 토큰 | 라이트 | 다크 | 용도 |
| --- | --- | --- | --- |
| `--bg` | `#f6f7f9` | `#0f1115` | 페이지 배경 |
| `--card` | `#ffffff` | `#171a21` | 카드·표 배경 |
| `--line` | `#e4e7ec` | `#2a2f3a` | 테두리, 표 구분선 |
| `--text` | `#111827` | `#e5e7eb` | 본문 |
| `--muted` | `#6b7280` | `#9ca3af` | 보조 텍스트, 표 헤더, 라벨 |
| `--accent` | `#2563eb` | `#60a5fa` | 주요 버튼 하나 |
| `--ok` | `#059669` | (동일) | 손익 플러스 |
| `--bad` | `#dc2626` | (동일) | 손익 마이너스, 오류 |

색은 이 8개뿐입니다. 그라데이션, 그림자, 아이콘, 일러스트는 쓰지 않습니다.
카드는 배경색 차이와 1px 테두리로만 구분합니다.

## 타이포그래피

- 폰트: 시스템 폰트 (`-apple-system, "Apple SD Gothic Neo", system-ui`). 웹폰트 로딩 없음.
- 본문 14px / 행간 1.5.
- 페이지 제목 20px 700. 하나만 있습니다.
- 섹션 제목 14px 600, `--muted`, 대문자·자간 0.04em. 제목이 아니라 구분선 역할입니다.
- 타일 숫자 24px 700. 타일 라벨 12px `--muted`.
- 표 헤더 12px 600 `--muted`. 표 본문 14px.
- 원시 데이터(JSON 등) 12px 모노스페이스 `--muted`.

## 레이아웃

- 최대 폭 1200px, 가운데 정렬, 좌우 여백 16px.
- 섹션 순서는 요약 → 분포 → 세션별 결과 → 전체 이벤트. 위로 갈수록 요약, 아래로 갈수록 원본입니다.
- 타일 그리드: `repeat(auto-fit, minmax(150px, 1fr))`, 간격 12px. 폭에 맞춰 알아서 줄바꿈합니다.
- 분포 카드 그리드: `minmax(260px, 1fr)`.
- 표는 카드 안에 넣고 가로 스크롤 허용(`min-width: 720px`). 모바일에서 표를 억지로 접지 않습니다.
- 모서리 반경: 카드 12px, 입력·버튼 8px, 종류 배지 999px.

## 컴포넌트

**요약 타일**
라벨(12px muted) 위, 숫자(24px bold) 아래. 단위나 설명은 라벨에 넣고 숫자는 숫자만.

**분포 카드**
제목 한 줄 뒤 항목별 `이름 ······ 개수` 행. 개수는 오른쪽 정렬 굵게. 막대나 파이 차트는 없습니다. 값이 없으면 "응답 없음"을 muted로.

**표**
- 헤더는 sticky, 카드 배경색.
- 행 구분은 1px `--line` 하단선만. 줄무늬 배경 없음.
- 셀 패딩 8px 12px, 기본 `white-space: nowrap`. 내용 열만 줄바꿈 허용, 최대 520px.
- 긴 ID는 앞 8자만 표시하고 전체 값은 `title` 속성으로.
- 종류 열은 배지(`.kind`). 배경 `--bg`, 테두리 `--line`. 색으로 종류를 구분하지 않습니다.
- 손익은 부호와 함께 `--ok` / `--bad`. 색을 쓰는 곳은 여기와 오류 문구뿐입니다.

**필터 바**
검색 입력, 종류 select, 스테이지 select, 건수, 그리고 오른쪽 끝에 CSV·새로고침 버튼. 모두 같은 높이(패딩 8px 10px), 같은 테두리.

**버튼**
기본 버튼은 카드 배경 + 테두리. `--accent`를 채운 primary 버튼은 화면당 하나(로그인의 "열기").

**로그인**
가운데 정렬, 폭 360px, 위 여백 80px. 제목·입력·버튼·오류 문구 네 줄. 실패 시 `--bad` 문구 한 줄만 추가.

## 하지 않는 것

- 아이콘, 이모지, 로고
- 그림자, 그라데이션, 애니메이션
- 차트 라이브러리. 분포는 숫자 목록으로 충분합니다.
- 상태 색 남용. 성공/실패 외에는 전부 회색 계열.
- 외부 CSS·JS·폰트. 파일 하나로 끝납니다.

## 새 섹션을 추가할 때

1. `<h2>`로 섹션 제목을 쓰고
2. 내용은 `.tile`, `.dist`, 또는 `.card > table` 셋 중 하나에 담습니다.
3. 새 색이 필요하다고 느껴지면 대부분 `--muted`로 해결됩니다.
